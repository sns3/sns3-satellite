Detailed Description

SatOrbiterFeederLlc holds the orbiter feeder implementation of LLC layer.

SatOrbiterFeederLlc is inherited from SatOrbiterLlc base class and implements the needed changes from the base class related to SAT feeder LLC packet transmissions and receptions.
